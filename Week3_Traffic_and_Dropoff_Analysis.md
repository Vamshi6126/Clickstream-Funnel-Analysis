In Week 3, I focused on analyzing website traffic performance and identifying user drop-off patterns within the clickstream funnel.

I created a new aggregated table to calculate session counts for each funnel stage (Homepage, ProductView, AddToCart, CheckoutStarted, Purchase) and built DAX measures for Sales by Traffic Source, Conversion Rate by Campaign, CPA, Sessions_AddedToCart, and Cart Abandonment %.

Next, I designed the Traffic Campaign Performance dashboard to visualize which marketing channels drive the most conversions and how efficiently each campaign performs.

I also built the Drop-off Analysis page with drill-through functionality, a last-page-before-drop-off chart, a device-wise drop-off analysis, and an insight summary explaining key user behavior patterns.

This completed the fully interactive Week 3 dashboard, giving the product team clear visibility into traffic quality, campaign performance, and user drop-off behavior.
