This week, I completed the customer journey analysis using session-level timestamps.
I created a new table with the first time a user reached each stage (Homepage, ProductView, AddToCart, CheckoutStarted, Purchase).
From these timestamps, I calculated the average transition time between every stage of the funnel.
Finally, I designed a clean Power BI dashboard that visualizes key journey time metrics, stage-wise averages, and a detailed session-level duration table.
This dashboard helps identify how long users take to move from one step to the next, and where delays or friction points may exist.
